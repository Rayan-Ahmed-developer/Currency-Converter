# 💱 Currency Converter

A modern and responsive Currency Converter web application built using HTML, CSS, and JavaScript. It allows users to convert currencies in real-time with an attractive and user-friendly interface.

## 🚀 Features

- Convert currencies instantly
- Real-time exchange rates
- Modern Glassmorphism UI
- Fully Responsive Design
- Country Flags Support
- Mobile Friendly
- Clean and Interactive Interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Currency Exchange API

## 🎯 How It Works

1. Enter the amount.
2. Select the source currency.
3. Select the target currency.
4. Click the **Convert** button.
5. View the converted amount instantly.
